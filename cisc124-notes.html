Week 1 — From Python to Java: Hello World & Basic Syntax

Key Ideas

  • Java is a compiled, statically typed language — types are checked at compile time.
  • Every program lives inside a class, and execution starts in public static void main(String[] args).
  • Java uses curly braces {} for blocks (not indentation like Python).
  • Every statement ends with a semicolon ;.
  • Java is case-sensitive — myVar and myvar are different.
Compile vs. Run: javac HelloWorld.java compiles to bytecode; java HelloWorld runs it on the JVM.

Hello World

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

Python → Java Quick Comparison

  • Print: Python print("hi") → Java System.out.println("hi");
  • Comments: Python # → Java // (single-line) or /* … */ (multi-line)
  • No indentation enforcement — use curly braces instead
  • Type declaration required: Python x = 5 → Java int x = 5;

User Input

import java.util.Scanner;

public class ReadInput {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter your name: ");
        String name = sc.nextLine();
        System.out.println("Hello, " + name + "!");
        sc.close();
    }
}

Week 2 — Primitive Types, Variables & Operators

Primitive Types

  • int — 32-bit integer (e.g. 42)
  • long — 64-bit integer (e.g. 10000000000L)
  • double — 64-bit floating-point (e.g. 3.14)
  • float — 32-bit floating-point (e.g. 3.14f)
  • boolean — true or false
  • char — single character in single quotes (e.g. 'A')
  • String — not a primitive; an object (uppercase S)

Variable Declaration & Assignment

int age = 20;
double gpa = 3.85;
boolean isEnrolled = true;
char grade = 'A';
String name = "Michael";

// Constants use the 'final' keyword
final double PI = 3.14159;

Arithmetic Operators

  • +, -, *, /, % (modulus)
  • Integer division truncates: 7 / 2 → 3
  • Use a double operand to get a decimal result: 7.0 / 2 → 3.5

Type Casting

int a = 5;
double b = (double) a;   // widening (safe)
int c = (int) 9.99;      // narrowing — truncates to 9

String Operations

String s = "Hello";
int len = s.length();           // 5
String upper = s.toUpperCase(); // "HELLO"
String sub = s.substring(1, 3); // "el"
boolean eq = s.equals("Hello"); // true  (use .equals(), NOT ==)
int pos = s.indexOf('l');       // 2
String joined = s + " World";   // concatenation
Never compare Strings with ==. Use .equals() to compare String content; == checks if they are the exact same object in memory.

Week 3 — Control Flow: Conditionals & Loops

if / else if / else

int score = 85;

if (score >= 90) {
    System.out.println("A");
} else if (score >= 80) {
    System.out.println("B");
} else if (score >= 70) {
    System.out.println("C");
} else {
    System.out.println("F");
}

switch Statement

int day = 3;
switch (day) {
    case 1: System.out.println("Monday");    break;
    case 2: System.out.println("Tuesday");   break;
    case 3: System.out.println("Wednesday"); break;
    default: System.out.println("Other");
}

while Loop

int i = 0;
while (i < 5) {
    System.out.println("i = " + i);
    i++;
}

do-while Loop

int n = 0;
do {
    System.out.println("n = " + n);
    n++;
} while (n < 3);
// Always executes at least once

for Loop

for (int j = 0; j < 10; j++) {
    System.out.println(j);
}

// Enhanced for-each (iterating a collection)
int[] numbers = {1, 2, 3, 4, 5};
for (int num : numbers) {
    System.out.println(num);
}

break & continue

for (int k = 0; k < 10; k++) {
    if (k == 5) break;     // exits the loop entirely
    if (k % 2 == 0) continue; // skips even numbers
    System.out.println(k); // prints 1, 3
}
Logical operators: && (AND), || (OR), ! (NOT). Short-circuit evaluation — Java stops early if the result is determined.

Week 4 — Methods & Scope

Method Anatomy

// accessModifier  returnType  methodName(paramType param, …)
public static int add(int a, int b) {
    return a + b;
}

public static void greet(String name) {
    System.out.println("Hello, " + name + "!");
    // void methods don't return a value
}

Calling Methods

int result = add(3, 7);      // result = 10
greet("Michael");            // prints: Hello, Michael!

Method Overloading

Multiple methods can share the same name if their parameter lists differ.

public static int multiply(int a, int b) {
    return a * b;
}

public static double multiply(double a, double b) {
    return a * b;
}

public static int multiply(int a, int b, int c) {
    return a * b * c;
}

Scope

  • Variables declared inside a method are local — only accessible within that method.
  • Variables declared inside a block {} are only accessible within that block.
  • Instance variables belong to an object (declared in the class body, outside methods).
  • Static variables belong to the class itself.

Recursion Example

public static int factorial(int n) {
    if (n <= 1) return 1;          // base case
    return n * factorial(n - 1);   // recursive case
}
// factorial(5) → 5 * 4 * 3 * 2 * 1 = 120
Pass by value: Java always passes primitives by value (a copy). Objects are passed by reference value — you can modify the object's fields, but not reassign the reference itself.

Week 5 — Arrays & ArrayList

Arrays (Fixed Size)

// Declaration and allocation
int[] scores = new int[5];          // {0, 0, 0, 0, 0}

// Declaration with initialization
String[] days = {"Mon", "Tue", "Wed", "Thu", "Fri"};

// Access and update
scores[0] = 95;
System.out.println(scores[0]);      // 95
System.out.println(days.length);    // 5 — note: .length not .length()

Iterating Arrays

int[] nums = {10, 20, 30, 40, 50};

// Traditional for loop (use when you need the index)
for (int i = 0; i < nums.length; i++) {
    System.out.println("nums[" + i + "] = " + nums[i]);
}

// Enhanced for-each (simpler when you don't need the index)
for (int n : nums) {
    System.out.println(n);
}

2D Arrays

int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

// Access element at row 1, column 2:
System.out.println(matrix[1][2]); // 6

// Iterate with nested loops
for (int row = 0; row < matrix.length; row++) {
    for (int col = 0; col < matrix[row].length; col++) {
        System.out.print(matrix[row][col] + " ");
    }
    System.out.println();
}

ArrayList (Dynamic Size)

import java.util.ArrayList;

ArrayList<String> courses = new ArrayList<>();

courses.add("CISC 124");
courses.add("MATH 112");
courses.add("BLCK 200");

System.out.println(courses.size());    // 3
System.out.println(courses.get(0));    // "CISC 124"

courses.remove("MATH 112");            // remove by value
courses.remove(0);                     // remove by index

// Iterate
for (String c : courses) {
    System.out.println(c);
}
Array vs ArrayList: Use int[] when the size is fixed and performance matters. Use ArrayList<Integer> when you need to add/remove elements dynamically. Note: ArrayList stores objects, so use wrapper types (Integer, Double, etc.).

Week 6 — Classes, Objects & Encapsulation

Defining a Class

public class Student {

    // Instance variables (fields) — private for encapsulation
    private String name;
    private int studentID;
    private double gpa;

    // Constructor
    public Student(String name, int studentID, double gpa) {
        this.name = name;
        this.studentID = studentID;
        this.gpa = gpa;
    }

    // Getters
    public String getName()       { return name; }
    public int getStudentID()     { return studentID; }
    public double getGpa()        { return gpa; }

    // Setters (with validation)
    public void setGpa(double gpa) {
        if (gpa >= 0.0 && gpa <= 4.3) {
            this.gpa = gpa;
        }
    }

    // toString — called automatically when printing the object
    @Override
    public String toString() {
        return "Student[" + name + ", ID=" + studentID + ", GPA=" + gpa + "]";
    }
}

Creating and Using Objects

Student michael = new Student("Michael", 20123456, 3.8);
System.out.println(michael.getName());    // Michael
System.out.println(michael);             // Student[Michael, ID=20123456, GPA=3.8]
michael.setGpa(3.9);
System.out.println(michael.getGpa());     // 3.9

Encapsulation Principles

  • Declare fields private — prevents direct external access.
  • Provide public getters and setters to control access.
  • Setters can validate data before storing it.

Static vs Instance

public class Counter {
    private static int count = 0;   // shared by ALL Counter objects
    private int id;                 // unique to each Counter object

    public Counter() {
        count++;
        this.id = count;
    }

    public static int getCount() { return count; }
    public int getId()           { return id; }
}

Counter a = new Counter(); // count = 1, a.id = 1
Counter b = new Counter(); // count = 2, b.id = 2
System.out.println(Counter.getCount()); // 2
this keyword: Refers to the current object. Use it to distinguish between a field and a parameter with the same name (e.g. this.name = name;).

Week 7 — Inheritance, Polymorphism & Interfaces

Inheritance (extends)

A subclass inherits the fields and methods of its superclass and can add or override them.

// Superclass
public class Animal {
    protected String name;

    public Animal(String name) {
        this.name = name;
    }

    public void speak() {
        System.out.println(name + " makes a sound.");
    }

    public String toString() {
        return "Animal(" + name + ")";
    }
}

// Subclass
public class Dog extends Animal {

    private String breed;

    public Dog(String name, String breed) {
        super(name);   // calls Animal constructor
        this.breed = breed;
    }

    @Override
    public void speak() {
        System.out.println(name + " says: Woof!");
    }

    public String getBreed() { return breed; }
}

Using Inheritance

Dog d = new Dog("Rex", "Labrador");
d.speak();                    // Rex says: Woof!
System.out.println(d.name);   // Rex (inherited from Animal — protected)

Polymorphism

A superclass reference can hold a subclass object. The correct overridden method is called at runtime.

Animal[] animals = {
    new Animal("Generic"),
    new Dog("Buddy", "Poodle"),
};

for (Animal a : animals) {
    a.speak();
    // Generic → "Generic makes a sound."
    // Dog    → "Buddy says: Woof!"
}

Abstract Classes

public abstract class Shape {
    // Abstract method — no body; subclasses MUST implement it
    public abstract double area();

    // Concrete method — shared by all shapes
    public void printArea() {
        System.out.printf("Area = %.2f%n", area());
    }
}

public class Circle extends Shape {
    private double radius;
    public Circle(double radius) { this.radius = radius; }

    @Override
    public double area() {
        return Math.PI * radius * radius;
    }
}

public class Rectangle extends Shape {
    private double width, height;
    public Rectangle(double w, double h) { width = w; height = h; }

    @Override
    public double area() {
        return width * height;
    }
}

Interfaces (interface / implements)

An interface defines a contract — any class that implements it must provide all listed methods.

public interface Printable {
    void print();          // implicitly public abstract
}

public interface Saveable {
    void save(String filename);
}

// A class can implement multiple interfaces
public class Document implements Printable, Saveable {
    private String content;

    public Document(String content) { this.content = content; }

    @Override
    public void print() {
        System.out.println(content);
    }

    @Override
    public void save(String filename) {
        System.out.println("Saving to " + filename);
    }
}

Interface vs Abstract Class

  • Use an interface to define a behaviour contract. A class can implement many interfaces.
  • Use an abstract class when sharing common code among related classes. A class can only extend one class.
  • From Java 8+, interfaces can have default method implementations.

instanceof Check

Animal a = new Dog("Max", "Husky");

if (a instanceof Dog) {
    Dog d = (Dog) a;   // safe downcast
    System.out.println("Breed: " + d.getBreed());
}
Key OOP Pillars: Encapsulation — hide data with private fields; Inheritance — reuse code with extends; Polymorphism — one interface, many implementations; Abstraction — hide complexity behind abstract classes/interfaces.
